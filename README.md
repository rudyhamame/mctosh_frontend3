# MCTOSH Frontend

This project uses Vite for development and production builds.

## Scripts

### `npm run dev`

Starts the local Vite dev server.

### `npm start`

Alias for `npm run dev`.

### `npm run build`

Builds the app into the `build` directory.

### `npm run preview`

Serves the production build locally.

## Project Notes

- The active HTML entry file is the root [`index.html`](./index.html).
- Files inside `public/` are served as static assets by Vite.
- `public/index.html` is a legacy file and is no longer the app entry point.
